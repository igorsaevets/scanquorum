# Support

## How to get help

Please search existing [issues](https://github.com/igorsaevets/scanquorum/issues) before creating new ones.

- Review the [README](./README.md) for getting started
- Open a [GitHub issue](https://github.com/igorsaevets/scanquorum/issues/new) for bug reports and feature requests
- Ask in [GitHub Discussions](https://github.com/igorsaevets/scanquorum/discussions) for questions and ideas
## Security issues

Please report security vulnerabilities privately. See [SECURITY.md](./SECURITY.md) for details.
